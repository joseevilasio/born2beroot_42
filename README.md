# Born2beroot

#### Finished in: 2024-07-22

## About

**Born2beroot** is a system administration project from 42 School that focuses on setting up a secure and functional Linux server using virtualization. The goal is to apply foundational knowledge in operating system configuration, user management, and service setup.

For this project, we configured a Debian-based virtual machine using **VirtualBox**, adhering to strict system requirements and security protocols. The bonus part included setting up a fully functional web stack using Lighttpd, MariaDB, and PHP to host a WordPress website.

Throughout the process, we learned to:
- Set up partitions and LVM (Logical Volume Manager)
- Configure and secure SSH access
- Implement password policies and sudo restrictions
- Install and configure services like NGINX and UFW
- Monitor system logs and user activity

## What I Learned

- Core Linux system administration skills
- How to apply the principle of least privilege
- Configuration of user groups and permissions
- How to script initial server setup for automation

## Bonus

In the bonus part of the project, I:
- Hosted a fully functional WordPress site using **Lighttpd**, **MariaDB**, and **PHP**
- Configured and tuned web services for basic performance and security
